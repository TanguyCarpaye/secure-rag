== Introduction and Goals

=== Requirements and Problem Statement

In high-tech industries (aeronautics, defense), engineering departments handle massive volumes of critical documentation. While leveraging foundation models via a Retrieval-Augmented Generation (RAG) architecture drives productivity, enterprise Information Security Policies (PSSI) strictly prohibit public internet data transit and third-party model retraining. 

The architectural challenge is entirely focused on infrastructure isolation and access governance. This Secure Enterprise RAG Platform delivers managed cognitive assistance with zero data flows leaving the corporate network.

==== Target Functional Capabilities
* **Async Ingestion:** Semantic vectorization of highly secure technical documents (PDF, Word, Markdown).
* **Hybrid Search:** Low-latency contextual retrieval via a managed vector database.
* **Grounded Inference:** Context-constrained generation using Mistral Large 3 via Amazon Bedrock.
* **Active Guardrails:** Synchronous PII masking and prompt injection blocking.

=== Quality Goals

Sealing the network perimeter and protecting intellectual property take absolute precedence over functional flexibility.

[cols="1,2,4", options="header"]
|===
|ID |Quality Objective |Description and Validation Metric

|*QG-1* 
|IP Protection and Data Isolation
|Zero intellectual property leakage. Zero data retention by model providers. Mandatory encryption via Customer Managed Keys (AWS KMS CMK) with strict segregation of duties.

|*QG-2* 
|Total Network Isolation
|Zero public internet transit. All workflows reside in private subnets without IGW/NAT Gateways. Exclusive use of AWS PrivateLink.

|*QG-3* 
|AI Safety and Integrity
|Deterministic blocking of prompt injections and out-of-scope queries. Automated redaction of PII via Bedrock Guardrails.

|*QG-4* 
|Serverless Operations
|Zero server administration. Serverless infrastructure (Bedrock, OpenSearch Serverless) deployed via Terraform.

|*QG-5* 
|FinOps and Performance
|Time to First Token (TTFT) < 1.2s; P95 latency < 4.0s. Granular tracking of token consumption via AWS Cost Allocation Tags.
|===

=== Stakeholders

[cols="1,3", options="header"]
|===
|Role / Entity |Primary Expectations

|*Chief Information Security Officer (CISO)*
|Verify PSSI/ISO 27001 compliance. Approve the air-gapped network topology, KMS CMK policies, and zero IP exfiltration guarantees.

|*Architecture Review Board (ARB)*
|Validate alignment with enterprise urbanization standards, the AWS Well-Architected Framework, and serverless ADRs.

|*Engineering Units (RandD / Design)*
|Accurate, hallucination-free cognitive assistance with verified, fast citations from technical baselines.

|*Platform and SecOps Team*
|Zero-maintenance infrastructure (serverless), fully reproducible IaC deployments, and strict IAM least-privilege enforcement.

|*FinOps Lead*
|Cost predictability enforced through strict token quotas, granular resource tagging, and optimized model routing.

|*Data Protection Officer (DPO / Legal)*
|Ensure GDPR/EU AI Act compliance, mandatory EU data residency (eu-west-3), and auditability of document access.
|===
